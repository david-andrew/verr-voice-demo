eSpeak NG 1.52.0 / Spellophone 0.2.1

This static app includes an untrained, rules-based pronunciation engine, used in a local Worker to translate words into phonemes. Lyrics are never sent to an external service.

eSpeak NG and the Spellophone wrapper are licensed under GNU GPL version 3 or later. Copyright remains with their respective contributors.

Corresponding source, including dictionary source, build scripts and patches: eSpeak NG 1.52.0 and Spellophone source. Follow the Spellophone README build instructions; its vendor pin selects eSpeak NG 1.52.0. Local packaging changes are documented in prepare_espeak.py; the worker bridge is phonemizer-worker.js.

The packaged JavaScript only removes source-map trailers; source maps are replaced by the corresponding source archive. The data manifest retains English, French and Greek dictionaries, matching this app’s supported dictionary languages. Compiled engine and dictionary bytes are otherwise unchanged.
